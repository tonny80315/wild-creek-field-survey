操作說明

  1. 部署到 GitHub Pages 後，用手機瀏覽器開啟網址，並加入主畫面即可作為 PWA 使用。
  2. 第一次開啟時請保持網路連線，讓系統快取頁面與資料；之後外業離線仍可開啟。
  3. 先選擇「鄉鎮市」，清單只會顯示該鄉鎮市的檢視資料。
  4. 填寫資料會先儲存在手機瀏覽器本機；設定 Web App URL 後，可按「同步上傳」寫入 Google 試算表。
  5. 照片會暫存在手機瀏覽器中；數量多時請定期匯出資料並另行備份原始照片。
  6. 完成後可匯出本筆或全部已填 CSV，再上傳 Google 雲端硬碟或回辦公室彙整。
